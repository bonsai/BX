# BX — Business X / BizX

**Business Transformation + Work Inheritance**
事業・ビジネスの構造を変え、そのワークを引き継ぎ、オーナーシップを持って回し、次へ渡す。

BX（BizX）は単なる業務改善ではない。価値提供・収益構造・組織・事業モデルを観測し、設計し、実験し、更新する。**同時に、生まれたワークを人間が引き継ぎ、回し、次へ渡す**。

## Two faces — 変える／引き継ぐ

```text
BX = Business Transformation + Work Inheritance
```

| Face | 何をするか | Cycle |
|---|---|---|
| **Transformation** | 事業の構造を変える | observe → model → strategize → design → experiment → measure → learn → update |
| **Succession** | ワークを引き継ぎ、回し、渡す | receive → understand → own → operate → handover |

変えるだけでは続かない。**引き継ぐ者がいて初めて事業は続く。**

## Succession Cycle — ワークを引き継ぐ

```text
receive（受け取る）
  ↓
understand（掴む）
  ↓
own（引き受ける）
  ↓
operate（回す）
  ↓
handover（渡す）
  ↺
```

| Step | 問い | 動詞 |
|---|---|---|
| receive | 何を受け取るか？ | 受け取る |
| understand | なぜやるのか？ | 掴む |
| own | 誰が責任を持つか？ | 引き受ける |
| operate | どう回すか？ | 回す |
| handover | 次は誰か？ | 渡す |

AX は「エージェントが実行する」層。BX は「**人間のビジネスパーソンがワークを引き継ぐ**」層。

## DX / AX / MX / BizX

| Layer | 対象 | 主体 |
|---|---|---|
| DX | 現場・業務・顧客・データ | DXer |
| AX | 変化を正確に捉え実行 | Agent / AX |
| MX | 市場・需要・顧客接点 | Marketer |
| **BX** | 事業・価値・収益・組織 ＋ ワークの引き継ぎ | Business Designer / Businessperson |

BX は、DX が変える現場・業務と、MX が観測する市場との間にある「事業」を変換対象として扱い、そのワークを引き継ぐ。

## Principle

1. Own the work.（引き受ける）
2. Understand before acting.（掴んでから動く）
3. Decide, then delegate.（決めてから任せる）
4. Make it continue without you.（自分がいなくても続く形にする）
5. Hand over explicitly.（明示的に引き継ぐ）
6. Agent is not the person.（演じるが本人ではない）
