# BizX

**Business Transformation** — 事業・ビジネスの構造を変える活動。

BizXは単なる業務改善ではなく、価値提供・収益構造・組織・事業モデルを観測し、設計し、実験し、更新するための実践モデル。

## BizX

BizXは「事業を回す人」ではなく、**事業の構造を設計・観測・更新する活動**として捉える。

## DX / AX / MX / BizX

| Layer | 対象 | 主体 |
|---|---|---|
| DX | 現場・業務・顧客・データ | DXer |
| AX | 変化を正確に捉え実行 | Agent / AX |
| MX | 市場・需要・顧客接点 | Marketer |
| BizX | 事業・価値・収益・組織 | Business Designer |

BizXは、DXが変える現場・業務と、MXが観測する市場との間にある「事業」を変換対象として扱う。
